# 🏥 CMR - Centro Médico Respiratorio | Frontend
Este repositorio contiene la aplicación web cliente para el Centro Médico Respiratorio (CMR)

El sistema permite la gestión integral de citas médicas con un enfoque basado en roles. Los pacientes pueden explorar los profesionales y servicios disponibles, y solicitar turnos. Por su parte, el personal médico y administrativo cuenta con un panel dedicado para administrar, reprogramar la agenda mediante operaciones CRUD completas y seguras.

## 🚀 Pasos para ejecutar la aplicación localmente
Para correr este proyecto en tu entorno de desarrollo, asegúrate de tener Node.js instalado y la API de Django corriendo en el puerto 8000.

1. Clonar el repositorio y acceder a la carpeta:

Bash
git clone <url-del-repositorio>
cd cmr-frontend
2. Instalar las dependencias:

Bash
npm install
3. Configurar Variables de Entorno:
Crea un archivo .env.local en la raíz del proyecto. Este archivo es necesario para que el frontend sepa a qué URL apuntar para consumir los datos.
